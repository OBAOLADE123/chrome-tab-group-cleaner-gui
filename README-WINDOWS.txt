TAB GROUP CLEANER - WINDOWS GUI
1. Install Node.js 20+ from https://nodejs.org (once).
2. Double-click setup.bat (once). It installs and builds the tool.
3. Double-click start.bat. A page opens in your browser.
4. Load my groups > search / select (shift-click selects a range) > Delete selected.
Backups are saved to C:\Users\<you>\.chrome-tab-group-cleaner\backups. Use "Restore a backup" to undo.
If your account syncs tab groups, read the yellow box in the app first.
